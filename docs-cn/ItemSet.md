# 物品套装（Item Set）

物品套装是一组物品的清单，并指定了把它们给予玩家的方式
（这些方式在上面的 _游戏（Game）_ 一章中已经说明）。
每个套装可以指定一个引擎、一副翅膀、一组可用物品和一组改装（Modification）。
只要了解了这些对象是什么（后续章节有说明），套装本身非常直观。
物品套装定义在 _sets.yml_ 文件中。

物品套装可以带有可选的 `class_name` 值：当该套装被应用到玩家身上时，
它将作为玩家的职业名称。如果应用了多个带名称的套装，以最后一个为准。

套装中指定的每件物品都可以有 `max` 值（限制玩家最多持有该物品的数量）
和 `min` 值（低于该数量后无法再出售）。

`refills` 设置控制应用该套装时是否补满玩家的所有物品。
一般来说你不会想要这个——买一枚火箭不应该顺便修好你的翅膀，对吧？
但如果你的等待室里有按钮，这个设置就有用了：即使玩家带有会提升
某些物品属性的改装，你也可以借此给出完全补满的物品。

items:
  item_set_name:
    class_name: [可翻译文本]
    engine: [引擎名]
    wings: [翅膀名]
    items:
    - [物品名]
    modifications:
    - [改装名]
    refills: [true/false]

## 物品套装设置

* `class_name`（**可选**）职业名称；玩家选择该套装后，其职业将使用此名称。
  如果玩家的套装组合里没有任何带名称的套装，玩家就没有职业名称。
* `engine`（**可选**）引擎名称，定义在 _engines.yml_ 中。
* `wings`（**可选**）翅膀名称，定义在 _wings.yml_ 中。
* `items`（**可选**）该套装中的物品列表，定义在 _items.yml_ 中。
* `modifications`（**可选**）改装列表，定义在 _modifications.yml_ 中。
* `refills`（**默认：false**）应用该套装时是否补满玩家的所有物品。
