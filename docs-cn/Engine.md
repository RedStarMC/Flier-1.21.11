# 引擎（Engine）

引擎是让玩家在飞行中加速的物品。每个引擎都是一件拿在**副手**的物品，
因此定义引擎时需要许多物品专属设置，比如 `material`。
每个引擎定义在 _engines.yml_ 文件中。每个引擎都有一个 `type`，
决定它的行为方式以及可用的附加设置。类型列表见下文。

engine_name:
  type: [引擎类型]
  [物品专属设置]
  max_fuel: [正小数]
  consumption: [非负小数]
  regeneration: [非负小数]
  [类型专属设置]

## 引擎设置

* `max_fuel`（**必填**）引擎拥有的燃料量。
* `consumption`（**必填**）加速时每刻（每秒 20 次）消耗的燃料量。
  设为 0 表示燃料无限。
* `regeneration`（**必填**）**未**加速时每刻恢复的燃料量。
  如果你想用恢复以外的方式补充燃料（比如增益道具），就把它设为 0。

## 引擎类型

每种引擎类型有不同的加速模型。

### 乘法引擎（Multiplying engine）

**`multiplyingEngine`**

该引擎把你当前的速度乘以 `acceleration`。这意味着你飞得越快，
加速就越快，直到达到 `max_speed`。如果你的飞行速度低于 `min_speed`，
则会以该速度为基准进行加速。利用这三个设置，你可以做出强劲但低速的
引擎，也可以做出孱弱但长时间加速后能达到极高速度的引擎，
以及介于两者之间的任何组合。

侧边栏上显示的速度会乘以 10，以免玩家被很小的数字困惑
（速度 3 其实已经很快了，所以显示为 30）。加速度每秒应用 20 次，
所以除非你想要瞬间达到极速，否则它需要是个非常小的值（比如 0.025）。

engine_name:
  type: multiplyingEngine
  [物品专属设置]
  [默认引擎设置]
  acceleration: [正小数]
  min_speed: [非负小数]
  max_speed: [正小数]

**迁移提示**：`material` 必须使用 1.21 的 Material 枚举名（如
`BLAZE_ROD`、`FEATHER`），旧配置中的 1.12 材料名会在加载时报
"Material does not exist" 错误。映射表见 _物品（Item）_ 一章。
