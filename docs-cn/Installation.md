# 安装

Flier 需要 Spigot 1.9 或更高版本。更早的版本因缺乏鞘翅物品而无法支持。运行本插件无需其他前置插件，但存在一些可选的集成功能。

要在你的服务器上安装 Flier，只需将 _Flier.jar_ 文件放入 _plugins_ 文件夹并重启或重载服务器即可。插件将自动生成其默认配置文件。如果你想立即设置示例游戏，你需要检查这些文件，将所有地点（Location）设置为正确的坐标值，并取消 `lobbies.yml` 中 `default` 大厅的注释。如果配置存在任何错误，它们将会显示在控制台中。

在创建你自己的游戏之前，请至少简要阅读一遍文档。

## 服务器设置建议

Flier 涉及大量高速飞行活动。这意味着你的服务器需要持续加载和卸载区块，并将它们发送给玩家。此外，玩家希望看到的视野范围远不止几秒钟的地形，因此你可能需要提高视距，这将对服务器产生更大的性能压力。

我的首要建议是**不要使用 CraftBukkit**。它的性能与原版 Minecraft 服务器相近，表现不佳。选择 Spigot 不仅能保证 Flier 100% 兼容，还能显著提升性能。

然而，即使是 Spigot 在快速加载/卸载区块时也会面临问题——区块加载卸载的速度可能快于 Java 清理内存的速度，这可能导致内存溢出（OutOfMemory）崩溃。解决方案是使用 **PaperSpigot**。它会在短时间内保留已加载的区块，虽然这会略微增加内存占用，但减少了频繁的内存清理开销，从而整体上降低了内存消耗。

拥有高性能的 CPU、大容量 RAM 和固态硬盘 (SSD) 也会有所帮助，但这比调整上述设置的成本要高得多。

由于 Spigot/Paper 对实体显示范围有可配置（但有限）的限制，建议将该范围至少增加到 256 格。Minecraft 客户端可能不会显示更远距离的实体，因此这是一个良好的服务端限制。这样玩家就能在更远的距离看到彼此（以及基于实体的道具加成）。

## 如何阅读本文档

每一章都介绍了 Flier 中的一个或多个对象。例如大厅 (Lobbies)、游戏 (Games)、动作 (Actions)、引擎 (Engines) 等。每个对象都在其对应的文件中定义。相应的章节会描述如何定义该对象：

*（建议查看 **Game（游戏）** 章节中的示例，以了解下述结构。）*

1.  首先，会解释该对象是什么，以及它与其他对象的一般关系。
2.  接着是该配置的结构模式 (Schema)，展示适用于该对象的所有选项，并指明这些选项所需的值的类型。
3.  之后会解释每个选项的作用，标明它是必填还是选填，如果是选填，则说明默认值。你必须定义所有必填值，如果跳过带有默认值的选项，则会使用默认值。跳过选填设置也是允许的。
4.  某些对象拥有子类型（例如，死斗模式就是游戏的一个子类型）。在这种情况下，子类型会在通用对象描述之后进行说明。
5.  在子类型名称的下方总会有一个关键词 (Keyword)。请在通用对象的 `type` 选项中使用该关键词，以告诉 Flier 你要定义的是哪个子类型。
6.  关键词下方是该子类型的描述。
7.  接下来是该对象类型的配置结构模式，与通用对象的结构模式类似。
8.  该模式通常包含一行 `[default object settings]`（默认对象设置）——此处应替换为第 2 点中显示的设置。
9.  在子类型模式下方是对其选项的解释，与第 3 点中的方式相同。

如果你在理解文档结构方面遇到任何问题，请查看插件生成的默认配置文件，并将其与本文档中的内容进行对比。
