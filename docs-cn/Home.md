# Flier

Flier 是一个鞘翅空中战斗小游戏插件，运行在 Paper 服务端上。它不包含任何常规 PvP 机制，
而是为玩家提供自定义引擎用于飞行，以及机枪、追踪导弹等武器用于互相击落对方。
命中目标和躲避攻击都需要技巧和预判。本插件高度可配置：你可以创建自定义游戏、
定义各种属性的物品，并在灵活的职业（套装）系统中使用它们。

Flier 是一个"易上手、难精通"的游戏——无论配置还是实战都是如此。你可以快速搭建
简单的游戏（甚至直接使用默认配置中的预设），也可以创建拥有大量规则和附加机制的
大型复杂游戏。

游玩 Flier 有很大的技术空间。用有限速度的弹射物命中飞行中的目标非常困难——
尤其因为目标前方没有红圈提示你该往哪里打。所有弹道计算都要在脑子里完成，
这是一项需要大量经验积累的技能。

## 特性

* 支持 **Paper 1.21.11** 及以上版本（需要 Java 21+）
* 多个游戏可同时运行
* 游戏类型：
    * 死斗（Deathmatch）
    * 团队战（Team game）
* 可配置的引擎与翅膀：
    * 加速度、速度
    * 空气阻力、升力
* 可自定义武器行为
* 强大的职业/套装系统
* 物品与武器的任意属性均可附加改装（Modifications）
* 效果（Effect）系统可为任何游戏内动作添加任意视觉效果
* 可拾取的增益道具（Bonuses）
* 可选集成 [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/)（游戏状态变量）

## 迁移说明（1.12.2 → 1.21.11）

本版本由 Spigot 1.9–1.12 时代的代码迁移至 Paper 1.21.11。迁移中的变更：

* 移除了 BetonQuest 集成（旧代码基于 BetonQuest 1.x API，与 2.x 不兼容，
  后续可按 BetonQuest 2.x API 重写该集成）
* 移除了 BountifulAPI 集成（该插件最高仅支持 1.10；标题与动作栏功能已改用
  高版本原生 API 实现）
* 材料名、音效名、粒子名已全部更新到 1.21 命名（旧配置中的 1.12 名称需要手工迁移，
  详见安装章节）
