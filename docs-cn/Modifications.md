# 改装（Modification）

改装用于修改玩家物品的各种属性——可以提升武器伤害、弹药容量、
引擎速度、火箭机动性等等。改装定义在 _modifications.yml_ 文件中。
每个改装必须针对单一类型的对象：引擎、翅膀、可用物品、动作或激活器。
它还必须指定一个对象名列表，修改器将应用到这些对象上。最后，
改装定义一个修改器列表——每个修改器对应匹配对象中要修改的一个属性。

stronger_weapon:
  target: [目标类型]
  names:
  - [对象名列表]
  modifiers:
  - [修改器列表]

在上面的例子中，当改装应用到持有 `balancedWeapon` 的玩家时，
会把该武器的翅膀伤害提高 35%，并给其物理伤害加 5。

## 改装设置

* `target` 改装的目标。可选值：
    * `engine`（引擎）
    * `wings`（翅膀）
    * `usable item`（可用物品）
    * `action`（动作）
    * `activator`（激活器）
* `names` 可以被此改装修改的对象名列表（定义在对应文件中，
  例如激活器在 _activators.yml_）。
* `modifiers` 属性修改器列表。每个修改器由键和值组成（`key: value`）。
  **这些修改器务必检查两遍**——控制台不会有任何报错，
  写错了会静默失败。可用的值类型：
    * 数字 —— 把属性替换为该数字（如 `4`）
    * 布尔值 —— 把属性替换为该布尔值（如 `true`）
    * 文本 —— 把属性替换为该文本（如 `arrow`）

## 高级数值修改器

来看这些修改器（作为某个改装的一部分）：

modifiers:
  damage: "*(0.35)"
  physical_damage: "+(5)"
  wings_off: true

上面的例子里有一些奇怪的语法：`*(0.35)` 和 `+(5)`
（它们被引号包起来，因为 YAML 不接受星号开头的字符串）。
它们分别是**乘数**和**加数**。乘数会取属性的当前值，
乘以你指定的数字，再加回该属性。例如 `0.35` 让属性提高 35%，
而 `-0.5` 让它降低 50%。如果有多个带乘数的修改器，
它们会先求和再应用。例如 `*(0.35)` 之后再 `*(-0.1)`，
属性总共提高 25%。

第二种是加数，直接加上你指定的数字。加法永远在乘法之后执行。
想减少属性就写成 `+(-10)`。这个语法看起来奇怪，
但它让插件解析这些值时更快。如果想让单个修改器既乘又加，
可以用逗号分隔两部分，例如：`+(20), *(0.5)`
（这里的顺序无所谓，乘数总是先应用）。
