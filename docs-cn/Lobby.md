# 大厅（Lobby）

大厅是 Flier 中最基本的对象。它包含游戏（一个或多个），管理玩家和场地（Arena）。
每个大厅定义在 _lobbies.yml_ 文件中。

本章会大量提到场地（Arena），下一章有详细描述。现在你只需知道：场地相当于
游戏的地图。大厅为玩家创建新游戏时，会从列表中选择一个空闲场地并把游戏分配给它。
游戏会指定自己可以使用哪些场地，大厅据此进行匹配。如果没有可用场地，
大厅就不会创建新游戏。

lobby_name:
  type: [大厅类型]
  name: [可翻译文本]
  spawn: [坐标]
  autojoin: [游戏 ID]
  max_games: [非负整数]
  games:
  - [游戏 ID 列表]
  arenas:
  - [场地 ID 列表]

## 大厅设置

* `type`（**必填**）大厅的类型。它决定大厅的表现形式（例如 `physicalLobby`
  是由方块构成的实体房间）以及可用的附加设置（例如房间必须有出生点）。
  可用类型见下文。
* `name`（**默认：`id`**）大厅的显示名称。
* `spawn`（**必填**）玩家加入大厅时的出生位置。游戏结束后玩家也会被传送回这里。
* `autojoin`（**可选**）指定游戏 ID 后，玩家进入大厅时会自动加入该游戏。
* `max_games`（**默认：0**）如果你有很多场地但服务器无法同时运行那么多游戏，
  可以用此设置限制同时运行的游戏数量。超过上限后即使有空闲场地也会拒绝
  创建新游戏。
* `games` 该大厅可用的游戏列表。玩家加入大厅时会启动列表中的第一个游戏。
  可以用 _flier setgame {大厅} {游戏}_ 命令切换当前游戏。
* `arenas` 该大厅可以分配游戏的场地列表。当玩家尝试加入游戏但现有游戏已满时，
  大厅会在第一个可以运行所选游戏类型的空闲场地上创建新游戏
  （见游戏设置中的 `viable_arenas`）。

## 大厅类型

### 实体大厅

**`physicalLobby`**

由实际方块结构组成的大厅，比如一个专门的房间。玩家通过点击指定方块来控制
加入、选择游戏和离开。包括：可散布在世界各处的 `join` 加入方块列表、
离开大厅的 `leave` 方块、开始游戏的 `start` 方块，以及一组物品套装方块。

lobby_name:
  type: physicalLobby
  [大厅设置]
  join:
  - [方块坐标列表]
  start: [方块坐标]
  leave: [方块坐标]

以上每个坐标都必须遵循统一坐标格式（Unified Location Format）：
`x;y;z;world`，前三个值是方块坐标，第四个是世界名称，例如：

`100.5;200;-300;concrete`

**迁移提示**：示例大厅默认是注释状态，因为坐标必须手工填写。取消注释前请把
所有 `100;200;300;world` 替换为你服务器上的实际坐标（可用
`/flier coordinator` 工具点击方块直接获取可复制的坐标串）。大厅还引用了
`games` 和 `arenas` 列表中的 ID——这些 ID 必须在 _games.yml_ 和
_arenas.yml_ 中存在定义，否则加载会报"游戏/场地不存在"错误。
